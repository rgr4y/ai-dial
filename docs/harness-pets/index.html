Harness dial pets

Every built-in pet and animation from openharness/devices/harness-device/firmware, decoded from the linked data in main/ui/habitat/pets.c (generated by scripts/gen_pets.py) by scripts/harness_pets_export.mjs. Placement, layering and timing are ported from focus.c and the rasterisers in terminal.c. Source tree is v0.0.94 (e673756). The device dump is v0.0.91 (firmware-backup/ota_0.bin), and all 34 palettes and 270 data arrays of pets.c appear byte-for-byte in it, so this is what the device draws.

The dial is 466 × 466 px at 1:1, glass circle r 233. The sprites are opaque palette cells: index 0 is transparent, and colours are RGB565 widened to 8 bits. Each animation's clock is clock_ms: step = ⌊clock / step_ms⌋ mod steps (focus.c:356).

Engine marks (engines without a pet show only a static mark; assets/engines/*.png, source art for the glyphs)
